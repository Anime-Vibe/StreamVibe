# StreamVibe — قالب موقع مشاهدة جاهز لأي محتوى

قالب موقع كامل (أفلام / مسلسلات / كرتون / أنمي — عربي أو إنجليزي) من غير أي بيانات أو فيديوهات.
كل التصميم والصفحات والبحث والمفضلة و"شاهد لاحقًا" شغالين — انت بس بتضيف المحتوى.

## الصفحات
| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية |
| `movies.html` | الأفلام |
| `series.html` | المسلسلات |
| `recommended.html` | مقترح لك |
| `top.html` | الأعلى تقييمًا |
| `watch.html` | صفحة المشاهدة |

## إزاي تضيف محتوى
افتح `data.js` وحط أعمالك جوه `MEDIA_DATA`. الشرح الكامل لكل حقل مكتوب فوق في نفس الملف.
- `type: "movie"` للفيلم و `type: "series"` للمسلسل.
- روابط التشغيل بتتحط في `servers` بصيغة `embed_url` (أي رابط iframe من أي مشغّل).
- `PAGE_DATASETS` بتحدد إيه اللي يظهر في كل صفحة. سيبها فاضية = كل المحتوى يظهر في كل الصفحات.

## التشغيل
- أسهل طريقة: افتح `index.html` مباشرة في المتصفح.
- أو بسيرفر محلي:
```bash
npm start
```
ويفتح على `http://localhost:3000`.

لو حبيت تدير المحتوى من ملف JSON بدل `data.js`، حط بياناتك في `db.json`
بالشكل `{ "series": [...], "movies": [...] }` والسيرفر هيقدمها على `/api/db`
والموقع هيحمّلها تلقائيًا.

## تغيير الاسم والهوية
- الاسم `StreamVibe` موجود في ملفات الـ HTML — غيّره لاسمك.
- روابط السوشيال في الفوتر فاضية (`href=""`) — حط لينكاتك.
- الألوان والخطوط في `style.css` و `watch.css`.
- صوت الخلفية `back_Sound.mp3` — استبدله أو امسحه.
